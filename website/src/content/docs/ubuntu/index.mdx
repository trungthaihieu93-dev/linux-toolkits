`linux-toolchain` is an interactive installer for 13 developer toolchains on
Debian and Ubuntu. Run it with `npx linux-toolchain` or `bunx linux-toolchain`,
choose the toolchains and options you want, and it installs and configures them.
Add `--dry-run` to print every script it would run without changing anything.
