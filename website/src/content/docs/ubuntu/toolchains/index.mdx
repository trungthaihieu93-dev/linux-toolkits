The toolchains install in this order. Each page lists the toolchain's
`--opt` keys, choices and defaults, its add-ons, and the toolchains it
depends on. A toolchain under **Requires** is added automatically unless it
is already installed.

These pages are generated from the CLI's own catalog
(`linux-toolchain list --json`) each time the site is built, so they follow
the source of the CLI. To see the catalog of the version you run, use:

```sh title="Terminal"
npx linux-toolchain list
```
